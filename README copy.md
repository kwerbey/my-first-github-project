# Kirby's IT Portfolio

A responsive personal portfolio built with HTML5, CSS3, and JavaScript.

## Run locally
1. Open this folder in Visual Studio Code.
2. Open `index.html` in your browser, or use the Live Server extension.
3. Replace the profile placeholder with your own photo and update the sample email address.

## Files
- `index.html` — page structure and content
- `style.css` — colors, layout, and responsive styling
- `script.js` — mobile navigation and contact-form validation
- `images/warm-plaid-hearts.png` — provided visual reference used subtly in the page background

## Before publishing
- Add your own profile image (for example, `images/profile.jpg`) and update the portrait area in `index.html`.
- Replace `kirby@example.com` with your actual public contact email.
- Add real screenshots of NU Mart and Bulldogs Xchange if you have them. The current project visuals are CSS-made illustrative previews, not screenshots of the actual systems.
- The contact form is a front-end demo. It validates fields but does not send messages until connected to a backend or form service.
